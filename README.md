# ⚡ Калькулятор заряду акумуляторів

Інтерактивний веб-калькулятор для точного розрахунку рівня заряду (SOC) акумуляторних батарей різних типів.

## 🌐 Використання

Відкрийте файл `index.html` у браузері або відвідайте сайт за посиланням (якщо налаштовано GitHub Pages).

## ✨ Можливості

- **4 типи акумуляторів**: GEL, AGM/WET, Li-Po/Ion, LiFePO₄
- **2 режими розрахунку**:
  - Напруга → % (розрахунок SOC за напругою)
  - % → Напруга (розрахунок напруги за SOC)
- **Налаштування конфігурації**: від 1S до 24S
- **3 стани акумулятора**: зарядка, розрядка, не підключений
- **Візуалізація**: інтерактивний індикатор рівня заряду

## 🛠️ Технології

- HTML5
- CSS3 (вбудовані стилі)
- Vanilla JavaScript (без залежностей)

## 📱 Сумісність

Працює у всіх сучасних браузерах без потреби у встановленні додаткового ПЗ.
